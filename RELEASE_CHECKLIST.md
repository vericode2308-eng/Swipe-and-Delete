# Lighter 1.0 — security audit and release checklist (Stage 10)

## Security audit (code and Release build, 2026-11-18)
- Network: no URLSession, no http(s) calls, no analytics or crash SDKs. Photos never leave the device. PASS
- Logging: no print / NSLog / os_log anywhere in App or Packages. PASS
- Storage: UserDefaults only (deletion count/date, review-prompt state). No photos, no identifiers. Privacy manifest declares it (CA92.1), tracking false, no collected data. PASS
- Debug hooks: `-debug.pro` is inside `#if DEBUG`; the string is absent from the Release binary. Products.storekit is not bundled. PASS
- Deletion: only `PhotoKitLibrary` deletes, and always behind the iOS confirmation prompt. PASS
- Permissions: one photo-library string, accurate. Limited access handled. PASS
- Secrets: no keys, certificates or profiles tracked in git. PASS
- Export compliance: `ITSAppUsesNonExemptEncryption` = false. PASS
- Release build (iphoneos, unsigned) succeeds; 48 + 1 + 41 package tests pass. PASS

## Findings
- F-1 (low): the Release bundle contains `AppIcon76x76@2x~ipad.png` although the app is iPhone-only. Harmless; remove the iPad icon slots if App Store Connect warns.
- F-2 (info): version/build live in both `project.yml` and `Info.plist`. Bump build number in `project.yml` for every upload (Info.plist is generated by XcodeGen).
